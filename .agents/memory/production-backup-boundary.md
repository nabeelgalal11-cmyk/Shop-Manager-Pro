---
name: Production backup boundary
description: Preserve host separation for production PostgreSQL dumps and Google Drive uploads.
---

Daily production PostgreSQL backups should run through the scheduled GitHub Actions workflow in a private repository. The user chose this to avoid Render billing and accepted GitHub Actions secrets as private from the public; the GitHub runner still handles the production URL at run time. Use Render's external connection URL for the live database, not its private/internal hostname, Replit's URL, or the separate `NEON_DATABASE_URL`. Keep the production URL only in GitHub Actions secrets; never send it to Replit. The GitHub Actions upload token must also be set in the receiver environment so the relay can identify the authenticated source. Limit repository write access to trusted workflow editors. The Replit deployment remains an authenticated relay that uploads verified dump bytes to connected Google Drive. HostGator Linux Shared currently lacks `pg_dump` and `pg_restore`. Keep dated backups unless the user requests retention or deletion.

For Drive provenance, authenticate Render uploads with `BACKUP_UPLOAD_TOKEN` and GitHub Actions uploads with a separate `GITHUB_ACTIONS_BACKUP_UPLOAD_TOKEN`. Configure the GitHub token on both the Replit receiver and in GitHub Actions, and do not accept a caller-supplied source label.

**Why:** The user does not want to add a payment card to Render, and HostGator Shared lacks the PostgreSQL client tools required for a complete dump. GitHub Actions' included runner allowance avoids a Render Cron service while Replit retains the Drive connector. Caller-supplied labels can be forged, so distinct bearer credentials are needed for reliable archive provenance.

**How to apply:** Keep the GitHub repository private, configure the external Render database URL and GitHub upload token as repository secrets, and do not add pull-request triggers or print secrets. GitHub Actions may block further runs if the included monthly minutes are exhausted without a payment method. PHP query access is not a substitute for a complete `pg_dump` archive. Keep the Replit `BACKUP_UPLOAD_TOKEN` and GitHub `GITHUB_ACTIONS_BACKUP_UPLOAD_TOKEN` distinct; set the latter in both the Replit receiver environment and the private repository's Actions secrets.
